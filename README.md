## Proyectos

### 1️⃣ Predicción de Rotación de Empleados

Proyecto de Machine Learning para predecir si un empleado abandonará la empresa.

Tecnologías utilizadas:

- Python
- Pandas
- Scikit-learn
- Seaborn
- Matplotlib

Modelo utilizado:

- K-Nearest Neighbors (KNN)

Resultados:

- Accuracy: 0.95
- AUC: 0.94
